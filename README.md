# Адаптивный сайт ресторана с меню и доставкой на дом


## 1. Описание проекта

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка» (практические занятия №9–11).

Пользователь может:

1. посмотреть меню и состав блюд, отфильтровать по категориям и найти блюдо по названию;
2. добавить блюда в корзину;
3. оформить доставку на дом с выбором способа оплаты;
4. узнать адрес, часы работы и ответы на частые вопросы;
5. найти блюдо, услугу или раздел через глобальный поиск (кнопка с лупой в шапке);
6. переключить светлую/тёмную тему — выбор сохраняется для всего сайта.

Backend не реализован, оформление заказа имитируется.

## 3. Технологии


HTML: семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`, `fieldset`)
CSS3: `css/custom.css` - только минимальные правки поверх Bootstrap
Bootstrap: сетка, компоненты, формы, утилиты
JavaScript: отрисовка меню, корзина, проверка формы заказа

## 5. Bootstrap-сетка и адаптивность

- `container`, `row`, `col-12 col-md-6 col-lg-4 col-xl-3` - карточки блюд: 1 / 2 / 3 / 4 в ряд;
- `g-3`, `g-4` — отступы между колонками;
- `navbar-expand-lg` + `navbar-toggler` - меню сворачивается в «бургер» на мобильных;
- `table-responsive` — таблица не ломает страницу;
- `img-fluid`, `object-fit: cover` — изображения не выходят за контейнеры;
- `d-grid` / `d-sm-flex` — кнопки на мобильных на всю ширину;
- проверено на 390, 768 и 1280 px.

## 6. Используемые компоненты

navbar, card, badge, btn (`btn-brand`, `btn-outline-brand`), modal (подробности блюда и успешный заказ), toast, accordion (FAQ), input-group, form-control, form-select, form-check, валидация `was-validated`.

## 7. Данные меню (`js/dishes.js`)

Массив `DISHES`: `id`, `name`, `cat`, `price`, `weight`, `img`, `label` (hit/new/veg), `desc`, `ingr`.
Чтобы добавить блюдо — положите картинку в `images/` и добавьте объект в массив.

## 8. Услуги, поиск и тема

- `js/services-data.js` — каталог из 12 услуг: `id`, `name`, `badge`, `price`, `img`, `desc`, `keywords`.
  Страница услуг и глобальный поиск используют один и тот же массив.
- `js/search.js` — поиск по блюдам, услугам и разделам сайта (`search.html?q=...`).
- `js/theme.js` — тема хранится в `localStorage` и cookie, применяется до отрисовки на всех страницах.
  Переключение — волной через View Transitions API (при `prefers-reduced-motion` — без анимации).
- `js/main.js` — корзина, тосты, тема, чат, хиты меню на главной.

## 9. Доступность

- ссылка «Перейти к основному содержимому»;
- у всех полей форм есть `label`, ошибки — через `invalid-feedback`;
- осмысленные `alt` у изображений, декоративные — с пустым `alt`;
- видимый фокус (`:focus-visible`), `prefers-reduced-motion`;
- таблица с `caption` и `scope`.
